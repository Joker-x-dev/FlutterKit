# 迁移指南（0.2.7 → 1.0）

> 来源：[迁移指南（0.2.7 → 1.0）](https://tdesign.tencent.com/flutter/getting-started)
> 归档时间：2026-10-30T16:00:00+08:00

适用于 tdesign_flutter 0.2.7 → 1.0.0，最低要求 Flutter ≥ 3.32.0、Dart ≥ 3.8.0。构造参数、状态和默认行为均有变化，不能只替换 TD 前缀。

依赖 ^1.0.0 可解析到后续 1.x 版本，以 pubspec.lock 为准。本文示例和 API 页面随配套源码维护；选择目标版本后，请核对更新日志。安装步骤见[快速开始](<快速开始.md>)。

## 升级顺序

1. 保留当前依赖锁文件、主题 JSON 与关键页面截图；先在业务分支迁移。
2. 升级到 Flutter ≥ 3.32.0、Dart ≥ 3.8.0。原生平台要求还受所解析的 Flutter/图片选择器实现包约束，按目标 SDK 构建验证。
3. 先替换公共主题/文字与导入，再迁移基础组件，最后迁移选择器、表单、浮层和异步交互。
4. 修复全部编译错误后，按本文的行为清单验证真实操作。默认视觉和回调行为变化不一定产生编译错误。

统一入口可同时提供 TD 与 Flutter Material 类型：

```dart
import 'package:tdesign_flutter/tdesign_flutter.dart';
```

仍可显式导入 Material；业务另有同名类型时用 import 前缀或 show/hide 解决。

## 按组件查找迁移方式

### 主题与全局配置

| 组件 | 旧入口 → 新入口 | 关键变化 |
| --- | --- | --- |
| Theme 主题 | TDTheme / TDThemeData → context.tTheme / TThemeData / TThemeBuilder | 先迁移全局主题，再调整组件 Theme 与局部文字样式 |

### 按钮、文字与基础组件

| 组件 | 旧入口 → 新入口 | 关键变化 |
| --- | --- | --- |
| Button 按钮 | TDButton → TButton | 内容改为 child，点击用 onPressed；传 null 禁用 |
| Divider 分割线 | TDDivider → TDivider | text/widget 合并为 child，direction → layout |
| Fab 悬浮按钮 | TDFab → TFab | onClick → onPressed，icon 改传 Widget |
| Icon 图标 | TDIcons / Icon → TIcons / TIcon | 图标数据使用外部包 tdesign_flutter_icons |
| Link 链接 | TDLink → TLink | 字符串内容改为 child: Text(...) |
| Text 文本 | TDText / TDTextSpan → TText / TTextSpan | 文字样式改为 TextStyle，缩放改为 textScaler |

### 页面导航与页签

| 组件 | 旧入口 → 新入口 | 关键变化 |
| --- | --- | --- |
| BackTop 返回顶部 | TDBackTop → TBackTop | onClick → onPressed |
| Drawer 抽屉 | TDDrawer → TDrawer / showTDrawer | 内容用 TDrawer(items:, title:, footer:) |
| Indexes 索引 | TDIndexes → TIndexes | 提供 indexList 与必填 builderContent |
| Navbar 导航栏 | TDNavBar → TNavBar | leading/actions 替代 leftBarItems/rightBarItems |
| SideBar 侧边栏 | TDSideBar → TSideBar | 去掉 selectTo，由 value 和 onChanged 管理 |
| Steps 步骤条 | TDSteps → TSteps.progress / selectable / display | 旧 activeIndex 改为 value |
| TabBar 标签栏 | TDBottomTabBar → TTabBar | 底部导航使用受控 value/onChanged |
| Tabs 选项卡 | TDTabBar / TDTabBarView → TTabsBar / TTabsBarView | 共享控制器；旧 isSlideSwitch 改为 physics |

### 表单、输入与选择

| 组件 | 旧入口 → 新入口 | 关键变化 |
| --- | --- | --- |
| Calendar 日历 | TDCalendar → TCalendar | 值改为 List<DateTime>；由 variant 决定单选/多选/区间 |
| Cascader 级联选择器 | TDCascader → TCascader | 数据改为 TCascaderOption 树，value 是 List 路径 |
| CheckBox 多选框 | TDCheckbox → TCheckbox | 单项使用 value/onChanged |
| DateTimePicker | TDDatePicker → TDateTimePicker | DatePickerModel 改为 TDateTimePickerValue |
| Form 表单 | TDForm → TForm / TFormField | 旧 items/rules/data 改为字段树 |
| Input 输入框 | TDInput → TInput | controller 与 initialValue 互斥 |
| Picker 选择器 | TDPicker → TPicker + TPickerColumns | 列数据改为 TPickerColumns；TPickerPopup 组合确认 |
| Radio 单选框 | TDRadio → TRadioGroup<T> | 单项放在同类型 TRadioGroup<T> 中 |
| Rate 评分 | TDRate → TRate | 使用必填 double value、onChanged |
| Search 搜索框 | TDSearchBar → TSearchBar | placeHolder/onTextChanged → hintText/onChanged |
| Slider 滑动选择器 | TDSlider → TSlider | 单值用 TSlider，区间用 TRangeSlider |
| Stepper 步进器 | TDStepper → TStepper | 提供必填 value，onChanged 接受候选数值 |
| Switch 开关 | TDSwitch → TSwitch | 提供必填 value；旧 fill 改为 TSwitchVariant.filled |
| Textarea | TDTextarea → TTextarea | 长度限制仍用 maxLength/maxCharacter |
| TreeSelect | TDTreeSelect → TTreeSelect | 受控 value 是 List<List<Object?>> |
| Upload 上传 | TDUpload → TUpload | 文件列表由 files/onChanged 管理 |

| 组件 | 旧入口 → 新入口 | 关键变化 |
| --- | --- | --- |
| ActionSheet 动作面板 | TDActionSheet → TActionSheet | 按意图选择 showList/showGrid；onClose → onClosed |

## 主题与文字

旧 TDTheme.of(context) 对应 context.tTheme；全局数据为 TThemeData，应用使用 TThemeBuilder.light/dark。

```dart
Widget migratedApp(Widget home) {
  final tokens = TThemeData.defaultData();
  return MaterialApp(
    theme: TThemeBuilder.light(tokens),
    darkTheme: TThemeBuilder.dark(tokens),
    home: home,
  );
}
```

使用 mergeExtension 合并子树组件主题，避免用 copyWith(extensions: [...]) 意外丢弃其他 ThemeExtension。

TText 的单实例文字使用 style: TextStyle(...)。textScaleFactor 改为 textScaler。

在线字体先由业务调用 TFontLoader.load 并管理加载状态。

旧 copyWithTDThemeData(name, marginMap: ...) 改为 copyWith(name: name, spacerMap: ...)。

旧公开 parseThemeData 不再可调用；统一使用 TThemeData.fromJson。

## 按钮与禁用语义

```dart
// 0.2.7: TDButton(text: '保存', type: TDButtonType.fill, onTap: save)
// 1.0:
Widget migratedButton(VoidCallback? onPressed) {
  return TButton(
    variant: TButtonVariant.fill,
    colorPreset: TButtonColorPreset.primary,
    onPressed: onPressed,
    child: const Text('保存'),
  );
}
```

onPressed == null 表示禁用。

## 受控值、输入与选择

受控组件需要父级接收回调并重建传回新值。TRadio 必须在同类型 TRadioGroup<T> 下。输入框的 controller 与 initialValue 互斥。

## 表单改为字段树

```dart
Widget migratedForm({
  required TFormController form,
  required TextEditingController text,
  required String value,
  required ValueChanged<String> onChanged,
}) {
  return TForm(
    controller: form,
    child: TFormField<String>(
      name: 'name',
      value: value,
      onChanged: onChanged,
      required: true,
      builder: (context, current, change, error) => TFormItem(
        label: '姓名',
        errorText: error,
        child: TInput(controller: text, onChanged: change),
      ),
    ),
  );
}
```

## Picker、日期与浮层确认分离

Picker 面板回调只是候选值变化，不是业务确认。使用 TPickerPopup.show 组合确认/取消。

Calendar 的 value 改为 List<DateTime>，single/multiple/range 由 variant 表达。

## Popup、Dialog、Toast

旧 TDPopup*Panel 组合改为 TPopup.show(context, options: ...)。TConfirmDialog 是单确认便捷组件。

Toast 时长用 Duration；持续加载用 Duration.zero。

## Upload 与平台依赖

files/onChange：迁为受控 files/onChanged。max/sizeLimit：改用 maxFiles/maxFileSize。

## 两种 TabBar 与 Swiper

顶部页签：旧 TDTabBar/TDTabBarView → TTabsBar/TTabsBarView。底部导航：旧 TDBottomTabBar → TTabBar。Swiper：使用 TSwiper；默认 loop/autoplay 均 false。

## 编译通过后仍要检查

- 控件禁用条件、受控回调回写、连续操作与异步完成后的状态。
- 主题明暗切换、局部 Theme、系统字体和 1/1.5/2 倍字号。
- 键盘、复制粘贴、输入法组合区、选区及焦点。
- 列表排序/选择、日期边界、滚轮惯性、Swiper 实际页码。
- 业务创建的控制器按其实际类型生命周期释放。

不存在替代入口的旧公开 State、Painter、布局适配类，不应通过深层 src 导入恢复。
