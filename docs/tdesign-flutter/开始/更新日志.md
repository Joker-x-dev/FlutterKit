## 🌈 1.1.0 2026-10-28

### 🚨 Breaking Changes

**升级提示**：本版本包含公开 API、默认行为和视觉变化。使用 tdesign_flutter: ^1.0.0 的项目可能解析到 1.1.0；升级前请检查以下兼容性影响，并回归相关业务场景。

- **TActionSheet**：命令式入口返回的 Popup 句柄默认在关闭后保留内容 State；重开时可复用，所属 Navigator 卸载时释放。替换会话时请检查 GlobalKey、Controller 和资源释放。(@RSS1102 #1197)
- **TButton**：child 中的 TText 默认接受按钮尺寸、配色和状态文案样式；显式字段优先，依赖原正文默认值的用法需明确样式。(@RSS1102 #1180)
- **TCheckboxGroup**：新增 onSelectionLimitExceeded，保留旧参数 onMaxSelected（implements 须补 getter）。(@RSS1102 #1196)
- **TDrawer**：新增 onItemTap / TDrawerItemTapCallback，保留旧参数（implements 须补 getter）。(@RSS1102 #1196)
- **Theme**：调整 Badge、SideBar、Cell 圆角，Table、Tabs、Toast 内边距，以及 BackTop、Dropdown、Refresh 图标的默认规格。将已核实的组件默认属性接入全局 Token。(@RSS1102 #1174 #1172)
- **TNavBar**：title 中的 TText 默认接受导航标题字体和颜色；复合标题及长标题可能改变布局。(@RSS1102 #1180)
- **TNoticeBar**：新增 onTargetTap，保留旧参数 onPressed（implements 须补 getter）。(@RSS1102 #1196)
- **TPickerPopup**：关闭后默认保留内容 State；1.0.0 关闭后始终释放，升级时请检查。(@RSS1102 #1197)
- **TPopover**：新增 onLongPress，保留旧 onLongTap（implements 须补 getter）。(@RSS1102 #1196)
- **TPopup**：TPopupOverlayConfig 改为 final class；关闭后默认保留内容 State；旧 onClick 保留但已废弃。(@RSS1102 #1199 #1197)
- **TSteps**：新增 onStepTapped，保留旧 onChange（implements 须补 getter）。(@RSS1102 #1196)
- **TTabBar**：新增 onSelected / notifyOnReselect，保留旧 onChanged / allowMultipleTaps（implements 须补 getter）。(@RSS1102 #1196)

### 🚀 Features

- **TBackTop**：新增 onCompleted，成功回顶后触发。(@RSS1102 #1193)
- **Theme**：新增 Badge 气泡圆角、Button 四档图标尺寸和 Tag 四档内边距配置。(@RSS1102 #1172)
- **TPopup**：新增蒙层点击回调 onTap，兼容旧入口。(@RSS1102 #1199)

### 🐞 Bug Fixes

- **DropdownMenu**：隔离共享 Controller 的状态与过期回调。(@lnuxe #1203)
- **TAvatar / TCalendar / TCollapse / TDivider / TLink / TProgress / TTable**：补齐对应 TText 默认样式。(@RSS1102 #1182)
- **TDialog**：修复 TText 标题与正文未应用弹窗文字样式的问题；修复文字操作区在长文案换行或文字缩放时的裁切。(@RSS1102 #1181 #1180)
- **TDrawer**：保留标题的 TD 段落设置；自定义菜单正文接入菜单默认字体。(@RSS1102 #1182 #1184)
- **TDropdownMenu**：修复旧组件解绑影响后绑定组件菜单命令的问题。(@RSS1102 #1191)
- **TFooter**：修复 Web 端链接文字被压缩后逐字竖排的问题；修复链接组换行后分隔线出现在行尾或独占一行的问题。(@liweijie0812 #1113)
- **TForm**：修复 Controller 替换失败后原绑定失效及卸载清理异常。(@RSS1102 #1191)
- **TNoticeBar**：修复自定义区域将拖动、长按、多指及鼠标按键组合误判为点击的问题。(@RSS1102 #1192)
- **TPicker**：自定义选项接入选中与禁用状态字体。(@RSS1102 #1184)
- **TPopover**：修复自然尺寸及单行、省略和支柱测量；自定义内容子树接入气泡默认字体和颜色。(@RSS1102 #1182 #1184)
- **TSteps**：自定义标题和说明接入对应方向及状态字体。(@RSS1102 #1184)
- **TSwipeCell**：修复 Controller 替换失败后原控制器无法继续控制的问题。(@RSS1102 #1191)
- **TSwiper**：修复重复提交无效 Controller 时绕过绑定校验的问题。(@RSS1102 #1191)
- **TTabBar**：自定义菜单项接入默认字体；修复菜单回调内导航或自行关闭后误关其他页面的问题。(@RSS1102 #1184 #1198)
- **TToast**：自定义普通/加载文案接入 Toast 默认字体和颜色；修复所属 Overlay 被遮挡后卸载时遗留实例和计时任务的问题。(@RSS1102 #1184 #1190)
- **TLoading / TMessage / TToast**：修复所属 Overlay 卸载后全局会话未自动释放的问题。(@RSS1102 #1190)
- **TPullDownRefresh**：修复未下拉刷新时顶部提示文字溢出绘制的问题。(@RSS1102 #1209)
- **TSlider**：修复滑块端点、数值和刻度的位置不对齐；修复受限尺寸及布局变化时滑块拖动异常。(@runoob-coder #1212)

## 🌈 1.0.0 2026-10-15

TDesign Flutter 1.0 正式发布！

本次版本围绕组件 API、主题体系、默认视觉和交互体验完成系统性升级，统一常用组件的使用方式，并增强表单、上传、选择器、图片预览、表格和轮播等能力。

### ✨ 本次发布重点

- **统一组件 API**：统一 T 前缀、内容插槽、回调与受控状态，梳理 Controller 和浮层职责，移除旧版兼容入口及重复配置。
- **完善主题体系**：通过全局 Token、组件 Theme、局部主题和实例配置定制样式，统一深浅色及主题切换表现。
- **提升视觉与交互一致性**：集中优化尺寸、排版、状态反馈、文字缩放和无障碍体验。
- **增强常用能力**：新增标准选择器弹层、上传列表与拖拽排序、图片预览缩放、自定义徽标，以及表格、轮播和进度条配置。

### 📖 升级到 1.0.0

1.0 包含不兼容的 API 和默认行为调整，最低要求 Flutter ≥ 3.32.0、Dart ≥ 3.8.0。

从 0.2.7 升级时，请先阅读[迁移指南](<迁移指南.md>)，按项目实际使用的组件迁移公共配置、参数、回调与业务流程。不能仅通过替换 TD 前缀完成升级；编译通过后，还需回归默认视觉、受控状态、确认/取消和异步操作。

### 🚨 Breaking Changes

**公共 API 与运行环境**

- 最低环境要求调整为 Flutter ≥ 3.32.0、Dart ≥ 3.8.0，移除历史 Flutter 版本适配依赖。
- 组件统一迁移到 T 前缀 API，移除旧构造、样式及辅助类型的兼容入口。
- TThemeData：统一全局 Token、组件 Theme、局部主题和实例配置的职责，移除重复的样式与行为入口；内置文字、图标、控件视觉由 TDesign 配置控制，不再继承外部 Material/M2/M3 的默认配置。
- 调整语义 Token 名称及默认颜色、字体、间距和圆角。
- 主题复制统一使用 copyWith(name: ..., spacerMap: ...)，移除旧 copyWithTDThemeData、ofColor/ofFont 等公开方法。
- TIcon / TIcons：图标迁移到 TIcon 与独立图标包 tdesign_flutter_icons。
- TButton：统一尺寸、点击热区和圆角，移除 filled 与 margin；配色选择参数由 colorScheme 改为 colorPreset。
- TText：普通文本与富文本统一对齐 Flutter 原生 Text 契约，内容参数改为必填；移除组件内字体下载、块背景、线性缩放等自定义能力。

（更多 Breaking Changes 见官方更新日志页面）

### 🚀 Features

- 全面引入 T 前缀组件体系
- 新的 TThemeBuilder 明暗主题构建方式
- TPickerPopup 标准选择器弹层
- TUpload 文件列表与拖拽排序
- TImageViewer.show 图片全屏预览
- TTable 完整表格能力
- TSwiper 原生轮播组件
- TProgress 多种进度条形态

### 🐞 Bug Fixes

- 修复多项主题 Token 缺失导致的默认值异常
- 修复组件在明暗切换时的状态同步问题
- 修复表单字段树的数据绑定问题
- 修复浮层关闭后的资源释放问题
