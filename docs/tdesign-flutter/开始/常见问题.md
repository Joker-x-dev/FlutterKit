# 常见问题

> 来源：[常见问题](https://tdesign.tencent.com/flutter/getting-started)
> 归档时间：2026-10-30T16:00:00+08:00

## 使用哪个版本和 Flutter SDK？

新项目可使用 tdesign_flutter: ^1.1.0。已有项目应根据依赖约束和锁文件确认实际版本。要求 Flutter ≥ 3.32.0、Dart ≥ 3.8.0。Android/iOS 最低系统版本还取决于实际解析的 Flutter 和平台插件，应在目标宿主构建验证。完整步骤见[快速开始](<快速开始.md>)。

## 从 0.2.7 升级，只替换 TD 前缀是否足够？

不足够。构造参数、回调、受控值、主题配置和已移除能力均可能变化，尤其要区分顶部页签与底部导航。请先阅读[迁移指南](<迁移指南.md>)。

## 为什么组件没有跟随 Material 主题变化？

TD 内置外观使用全局 Token、组件 Theme 及公开实例配置。Material 的按钮主题、文字主题或 IconTheme 不作为 TD 内置视觉的隐式覆盖入口。配置方法见[自定义主题](<../全局配置/自定义主题.md>)，明暗模式也在同一指南中。

## 为什么切换主题后仍显示默认颜色？

先检查是否通过当前子树的 context.tTheme 读取颜色，是否错误地固定使用 TThemeData.defaultData()；再检查读取 context 是否位于新 Theme 之下。局部覆盖使用 mergeExtension，避免重建 extensions 列表时丢失其他主题扩展。

## 点击、输入或选择后，为什么值不变化？

受控组件需要父级接收回调、更新状态并把新 value 传回。仅记录回调不会更新业务值。输入框的 controller 和 initialValue 互斥，initialValue 只用于初始化。具体要求见 Input、Checkbox 等组件 API。

## 输入内容为什么被过滤？如何调整高度？

按所需规则配置 Flutter 的输入格式化器。FilteringTextInputFormatter.allow 保留新编辑值中匹配的片段，过滤其余内容；不要使用 ^、$ 校验整个输入值。需要接受或拒绝完整编辑值时，使用 TextInputFormatter.withFunction。输入框布局、内容间距应通过当前组件 API、Theme 和合理的外部约束配置。参见 Input 和 Textarea。

## Toast 应该使用哪个 context？加载提示如何关闭？

使用目标 Navigator 和 Theme 子树中仍处于挂载状态、能够访问 Overlay 的 context；异步操作后先检查 context.mounted。避免长期缓存页面 context 或用全局 context 绕过局部主题。持续加载需要显式 Duration.zero 并在业务结束后关闭；具体句柄和关闭方式见 Toast 及迁移指南。

## 图片是否有独立缓存配置？

TImage 使用 Flutter 的 Image/ImageProvider 机制。缓存与图片来源、ImageProvider 及 Flutter 图片缓存有关，不应假定每次重建都会重新下载。

## 为什么组件文案没有随应用语言更新？

检查完整资源代理是否已注册，读取 context 是否位于 Localizations 之下，切换语言后是否仍缓存旧代理。对接方式与检查清单见[国际化](<../全局配置/国际化.md>)。

## 如何调整文字居中与行高？

使用 textAlign、外部 Center/Align 以及 style、strutStyle、textHeightBehavior；不再使用旧版字体 padding 补偿。见 Text。

## 弹层如何避让安全区？

TPopup 和 TPickerPopup 默认不避让安全区。设置 useSafeArea: true 会移动整个面板，面板背景也随之离开屏幕边缘；如需背景贴边，可保持默认配置，在内容中使用 SafeArea 避让需要的边。避免外层弹层与内部组件重复处理同一边的安全区。

## 如何反馈问题或申请组件能力？

先查看当前组件 API 和示例，确认问题后在 GitHub Issues 提供组件版本、Flutter 版本、运行平台、最小复现及预期结果。提交修复前阅读[贡献指南](<贡献指南.md>)。
